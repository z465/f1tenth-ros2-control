# F1TENTH ROS2 Control

This repository is based on the original [AutoDRIVE ADSS Toolkit ROS2](https://github.com/Tinker-Twins/AutoDRIVE/tree/AutoDRIVE-Devkit/ADSS%20Toolkit/autodrive_ros2) project.

I use the AutoDRIVE DevKit to develop ROS2 nodes for the F1TENTH vehicle in AutoDRIVE Simulator. This repository works together with a separate VLM/VLA inference repository. The ROS2 side saves front-camera images, reads the action result generated by the VLM, and publishes control commands to the simulated F1TENTH car.

## New Package

This repository adds a new ROS2 package:

```text
my_f1tenth_control
```

## Executables

The package provides the following executable nodes:

1. `image_saver`
   Subscribes to the F1TENTH front-camera topic and saves camera images to a shared folder.

2. `f1tenth_vlm_control`
   Reads the latest action generated by the VLM inference script and publishes throttle and steering commands to the F1TENTH vehicle.

3. `f1tenth_init`
   Initializes the F1TENTH car before running the VLM-based control pipeline.

## System Overview

The complete pipeline is:

```text
AutoDRIVE Simulator
        ↓
AutoDRIVE DevKit ROS2 topics
        ↓
image_saver
        ↓
shared image folder
        ↓
VLM/VLA inference repository
        ↓
latest_action.txt
        ↓
f1tenth_vlm_control
        ↓
throttle and steering commands
        ↓
F1TENTH vehicle in AutoDRIVE Simulator
```

## Shared Folder

This ROS2 repository is designed to work with a separate VLM/VLA inference repository through a shared folder.

The `image_saver` node writes front-camera images to:

```text
.../Qwen-VL-Series-Finetune/data/images
```

The VLM/VLA inference script reads images from this folder and writes the latest action to:

```text
.../Qwen-VL-Series-Finetune/data/latest_action.txt
```

The `f1tenth_vlm_control` node reads `latest_action.txt` and converts the action into F1TENTH control commands.

## Supported Actions

The VLM/VLA inference side outputs one of the following actions:

```text
forward
turn left
turn right
stop
backward
```

The ROS2 control node maps these actions to throttle and steering commands.

## Relation to the VLM/VLA Repository

This repository is responsible for:

* subscribing to AutoDRIVE ROS2 topics
* saving front-camera images
* reading the latest VLM-generated action
* publishing throttle and steering commands

The VLM/VLA repository is responsible for:

* loading the vision-language model
* reading the saved front-camera images
* generating reasoning and action suggestions
* writing the latest action to a shared file
